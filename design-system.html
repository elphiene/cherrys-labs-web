design system

A living, component-level reference for cherry's labs — extracted from style.css. This is for whoever's building the next page or component (El, cherry, or Claude): use the tokens and patterns below as-is, don't invent new ones. For brand voice, logo direction, and asset strategy, see brand/cherrys-labs-brief.md — that doc is the source of truth for identity; this page is the source of truth for implementation. If the two ever disagree, style.css wins.

Sections marked proposed describe components the site doesn't have yet (buttons, form fields, alerts, tables, a formal empty state). They're built from existing tokens and are ready to merge into style.css if/when they're needed — nothing on the live site currently depends on them.

layout patterns

Fixed glass header (pink-tinted gradient, pink glow shadow) on every page. Content is capped at 1200px and centered. Sections are separated by a soft horizontal gradient divider — visible above and below this block.

That's the divider: section:not(:last-child)::after — a 1px gradient line, transparent → white 30% → transparent.

buttons

The site has never needed a real button — every action is a link (nav, card links, hamburger). As soon as something needs a real call-to-action (a form submit, "load more," a store checkout button), it should use one of these rather than styling a one-off <a>.

.btn { font-family: var(--font-heading); padding: 11px 22px; border-radius: calc(var(--radius) / 2); }
.btn-primary  { background: linear-gradient(135deg, var(--color-pink), var(--color-purple)); color: #fff; box-shadow: var(--shadow); }

do / don't

do

Pure black backgrounds. Pink-led accents with purple in support. Glass surfaces with strong blur. Soft neon glow on hover/focus. Lowercase copy. Audiowide for anything heading-level.

don't

Light backgrounds. Flat material-style cards with hard shadows. Rubik Glitch outside of special moments. Dropping the glow — it's the signature. Title-case nav labels.

Full brand voice, logo direction, and asset checklist (wallpaper, screensaver, business cards) live in brand/cherrys-labs-brief.md — this page only covers implementation-level tokens and components.
