non-steam-grid-generator

overview

complete HTML CSS JS Canvas API Web

A single-page browser tool for generating correctly sized Steam artwork for non-Steam games. Upload a logo, set a title and colours, and it outputs all five Steam artwork types as PNG files — ready to import directly into Steam.

Runs entirely in the browser. No install, no account, no server. Live at cherrygaysoda.github.io/Non-Steam-Grid-Generator.

generated assets

Five Steam artwork types are produced per generation:

assetdimensionscontent
Library Capsule600×900pxVertical — logo in upper third, game title below
Library Header920×430pxHorizontal — logo left-aligned, title at bottom-right
Hero Graphic1920×620pxWide cinematic — background only, no text or logo overlay
Library Logo1280×720pxCentred logo on coloured background
Icon256×256pxSmall square — centred logo, no text

Files are named [gametitle]_[assettype]_[dimensions].png and downloaded sequentially.

usage

Configuration panel (left side):

  • Game title text input
  • Logo / icon image upload
  • Optional background image upload
  • Background colour picker with eyedropper (samples from uploaded image)
  • Font selector — 11 options including Orbitron, Black Ops One, Audiowide
  • Text weight: Regular / Bold / Black
  • Text colour picker
  • Text size slider: 50–200%
  • Logo size slider: 20–80%
  • Toggles: text stroke, drop shadow, blur background, darken background

Click Generate to render all canvases, then Download to save all five files.

tech stack

Pure HTML / CSS / JavaScript — no frameworks, no dependencies, no build step. A single index.html file.

Image processing uses the HTML5 Canvas API. Images are loaded as Image objects and rendered onto five canvas elements with cover-fit scaling. Optional effects: 10px blur, 40% darkening overlay.

Text rendering automatically wraps and scales down if it exceeds maximum width. Drop shadow and stroke are applied via canvas context before text draw. Multi-line text uses 1.2× font size line-height.

Download converts each canvas to a PNG blob sequentially with 300ms delays to allow the browser to process each file.
