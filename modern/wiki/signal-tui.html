signal-tui

overview

A terminal user interface for Signal messenger, built with Python and Textual. Runs on top of signal-cli as a background daemon, giving you full Signal messaging from the keyboard — send and receive text, manage contacts, get read receipts, and receive smart notifications — without ever leaving the terminal.

Comes with 6 built-in colour themes (retro-green, cyberpunk-pink, nord, gruvbox, dracula, solarized-dark) plus fully custom presets defined in a YAML config file.

tech stack

Language: Python 3.10+.

UI framework: Textual — reactive TUI framework built on top of Rich. Widgets include a contact list, message list, input box, status bar, info panel, and notification bar.

Signal backend: signal-cli runs as a background daemon and exposes a JSON-RPC socket. Signal-TUI communicates with it to send messages, receive incoming messages in real time, and manage the linked device.

Storage: Contact names persisted in ~/.config/signal-tui/contacts.json; message history in a local store. All configuration lives at ~/.config/signal-tui/config.yaml.

architecture

Signal-TUI sits as a thin Python application on top of signal-cli. The app manages the Textual UI event loop, coordinates the daemon lifecycle (start, stop, restart via r), and subscribes to the JSON-RPC receive endpoint for real-time incoming messages.

Linking a device requires scanning a QR code with your Signal mobile app once; after that signal-cli handles token refresh automatically. An in-app l shortcut launches the device linking flow via link_device.py.

Themes are pure Python dicts in themes.py — each preset maps semantic colour names (primary, secondary, background, text, …) to hex values that are injected into Textual CSS at startup.

setup

Install signal-cli first (via package manager on Arch, manual download on Debian/Ubuntu, or Homebrew on macOS), then link your Signal account as a secondary device. After that, run the install script:

git clone https://github.com/elphiene/signal-tui && cd signal-tui && ./install.sh

The install script creates a Python virtualenv, installs all dependencies from requirements.txt, and registers a desktop launcher. Launch from the application menu or via python -m signal_tui.app from the activated venv.

keyboard controls

Enter — send message  |  Tab / Shift+Tab — switch between contact list and info panel  |  Up/Down — navigate contacts

n — new conversation  |  e — edit contact name  |  r — refresh / restart daemon  |  l — link new device  |  c — open config file  |  q — quit
