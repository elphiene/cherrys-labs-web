signal-tui

overview

A terminal user interface for Signal messenger built with Python and Textual. Signal-TUI wraps signal-cli to provide a keyboard-driven, themeable chat experience — send and receive messages, manage contacts, and track read receipts, all from the terminal.

Designed for Linux. Requires signal-cli installed and a Signal account linked as a secondary device. The app manages signal-cli as a background daemon and communicates with it over its JSON-RPC socket.

tech stack

Language: Python 3.10+.

TUI framework: Textual by Textualize — a reactive, async terminal UI library for Python.

Signal backend: signal-cli — a Java CLI tool for the Signal protocol. Signal-TUI starts signal-cli as a daemon and drives it via its JSON-RPC interface over a Unix socket.

Config: YAML at ~/.config/signal-tui/config.yaml. Contact names are persisted as JSON.

themes

Six built-in colour presets: retro-green, cyberpunk-pink, nord, gruvbox, dracula, and solarized-dark.

Custom themes are fully supported — set theme.preset: "custom" in the config and define your own colour palette, or register a named custom preset under theme.custom_presets.

development

The application is split into a daemon manager (daemon.py), a Signal JSON-RPC client (signal_client.py), contact and message stores, theme definitions, and a set of Textual widgets (contact list, message list, input box, status bar, info panel) and modal screens (link device, new conversation, edit contact).

Smart notifications only fire for messages outside the currently active conversation. Read receipts are tracked and displayed per-message. The info panel shows conversation statistics alongside the message history.

Installation uses install.sh — creates a Python virtualenv, installs pip dependencies, and registers a .desktop launcher. Updates are handled by update.sh.
