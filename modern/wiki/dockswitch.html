dockswitch

overview

A Rust utility that monitors dock connection events via libudev and automatically switches SteamOS between Gaming Mode and Desktop Mode, allowing seamless transitions between handheld and desktop use.

Status: complete. Distributed as an AppImage. MIT licensed.

tech stack

Language: Rust. Target: SteamOS / Linux.

Dock detection: libudev — monitors kernel udev events for dock connect/disconnect. Build dependencies: libudev-dev, libwayland-dev, libgl-dev.

Distribution: AppImage (DockSwitch-x86_64.AppImage). The installer writes a sudoers rule once, then runs as a daemon on every login — no manual service management needed.

setup

1. Download DockSwitch-x86_64.AppImage from the releases page.

2. Make it executable and run it: chmod +x DockSwitch-x86_64.AppImage && ./DockSwitch-x86_64.AppImage

3. Click Install Daemon — prompts for password once to write a sudoers rule.

4. Click Register Dock — connect your dock, check the devices that identify it, save.

Done. The daemon starts on login and switches sessions automatically.

build from source

cargo build --release
./build-appimage.sh   # produces DockSwitch-x86_64.AppImage
