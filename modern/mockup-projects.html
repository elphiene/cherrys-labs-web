tidal-collaborative

A self-hosted server that lets multiple users collaboratively sync Tidal playlists in real time. Sign in via OAuth, link a playlist, and changes propagate to all collaborators within 60 seconds via WebSocket push. Runs on Docker, home lab friendly — amd64 and arm64.
