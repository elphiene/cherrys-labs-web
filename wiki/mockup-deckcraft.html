deckcraft

overview

wip JavaScript SteamOS Linux

A Minecraft launcher built specifically for Steam Deck, designed to make installing and managing Minecraft straightforward on SteamOS. Aims to solve the friction of getting Minecraft running well in both handheld and desktop modes.

Currently in active development. Repository is private while work is ongoing.
