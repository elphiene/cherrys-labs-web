tidal-collaborative

overview

wip Node.js Docker Self-hosted

A self-hosted server that lets multiple users collaboratively sync Tidal playlists in real time. Sign in with your Tidal account in any browser, link a playlist to a shared playlist, and every change — tracks added or removed — propagates to all collaborators automatically.

Designed for home lab deployment via Docker. Requires a free Tidal developer app registration for OAuth. Users must be on the same LAN or connected via VPN.

how it works

The server polls each linked Tidal playlist every 60 seconds. It detects added and removed tracks via set-difference against a cached snapshot, writes changes to SQLite, calls the Tidal API to propagate those changes to every other linked user's playlist, then broadcasts a WebSocket notification to all open browser tabs instantly.

When a new user links their playlist, the system immediately seeds their playlist with the current shared state and runs an initial poll cycle — so they're in sync before the next scheduled poll.

Conflict resolution uses last-write-wins semantics. Track additions are idempotent, preventing duplicates.

database schema

Six SQLite tables:

tablepurpose
usersEncrypted Tidal access and refresh tokens per user
settingsConfiguration — admin PIN, Tidal client ID, encryption key
shared_playlistsAdmin-created collaborative playlist records
playlist_linksMaps a user's Tidal playlist to a shared playlist
tracksTrack metadata with soft-delete support
active_usersWebSocket presence data

The entire state lives in one file — backup is a single cp.

security

OAuth PKCE — authentication is handled entirely server-side. No Tidal token ever touches the browser.

AES-256-GCM — Tidal access and refresh tokens are encrypted at rest. A stolen database file cannot be used to access Tidal accounts.

Session cookies — httpOnly, 30-day expiry. WebSocket connections are authenticated via the same session cookie during HTTP upgrade.

Admin PIN — 4-digit PIN gates the admin panel. Set on first access, stored in the settings table.

setup

Pull from Docker Hub — no build needed:

curl -O https://raw.githubusercontent.com/elphiene/tidal-collaborative/master/docker/docker-compose.yml
docker compose up -d

Then open http://localhost:3000. The setup wizard handles everything — it generates encryption keys automatically and walks you through connecting your Tidal developer app.

System requirements: Linux, Docker Engine 24+ with Compose plugin v2+, ≥128 MB RAM, ≥100 MB disk.

For development without Docker:

cd server && npm install && npm start
