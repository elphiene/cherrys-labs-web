dockswitch

overview

complete Rust SteamOS Linux MIT

A Rust utility that monitors dock connection events via libudev and automatically switches SteamOS between Gaming Mode and Desktop Mode — letting you seamlessly move between handheld and desktop use without touching a menu.

Ships as an AppImage. Install the daemon once and it handles everything from that point on, starting automatically on each login.

Build dependencies: libudev-dev, libwayland-dev, libgl-dev.

setup

  1. Download DockSwitch-x86_64.AppImage from the releases page.
  2. Make it executable and run it: 
    chmod +x DockSwitch-x86_64.AppImage
./DockSwitch-x86_64.AppImage
  3. Click Install Daemon — prompts for your password once to write a sudoers rule. No further sudo needed after this.
  4. Click Register Dock — connect your dock, check the devices listed that identify it, then save.

Done. The daemon starts on login and switches sessions automatically whenever the dock is connected or disconnected.

build from source

cargo build --release
./build-appimage.sh

Produces DockSwitch-x86_64.AppImage. Requires Rust toolchain, libudev-dev, libwayland-dev, and libgl-dev.
